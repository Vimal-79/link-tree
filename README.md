# Linktree Clone

A responsive Linktree-inspired landing page built with Next.js, React, and Tailwind CSS. The project recreates a modern creator-focused website with animated image slides, feature sections, testimonials, and authentication pages.

## Features

- Responsive landing page
- Animated image carousel
- Creator and monetization feature sections
- Testimonials and featured-brand sections
- Login and signup pages
- Tailwind CSS styling

## Tech Stack

- Next.js 15
- React 19
- Tailwind CSS 4
- JavaScript

## Getting Started

### Prerequisites

- Node.js 18 or later
- npm

### Installation

```bash
git clone https://github.com/your-username/link-tree.git
cd link-tree
npm install
```

### Run Locally

```bash
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) in your browser.

## Available Scripts

```bash
npm run dev    # Start the development server
npm run build  # Create a production build
npm run start  # Start the production server
npm run lint   # Run lint checks
```

Build and deploy the project with any platform that supports Next.js, such as Vercel:

```bash
npm run build
```
